# Go 简单聊天程序

这是一个使用 Go 语言编写的简单 TCP 聊天程序，包含服务器端和客户端。

## 功能特性

- 多用户实时聊天
- 用户昵称设置
- 在线用户列表查看
- 时间戳显示
- 优雅的连接管理

## 文件结构

```
chat_app/
├── server.go    # 聊天服务器
├── client.go    # 聊天客户端
├── Makefile     # 构建脚本
└── README.md    # 说明文档
```

## 使用方法

### 方法一：使用 Makefile（推荐）

1. 编译程序：
   ```bash
   make build
   ```

2. 启动服务器（在第一个终端）：
   ```bash
   make run-server
   ```

3. 启动客户端（在第二个终端）：
   ```bash
   make run-client
   ```

### 方法二：直接运行

1. 启动服务器：
   ```bash
   go run server.go
   ```

2. 启动客户端：
   ```bash
   go run client.go
   ```

## 使用说明

### 服务器端
- 默认监听端口：8081
- 自动为每个连接的客户端分配唯一ID
- 支持多客户端同时连接

### 客户端
连接后需要输入昵称，然后可以：
- 直接输入消息进行聊天
- 输入 `/list` 查看在线用户
- 输入 `/quit` 或 `/exit` 退出聊天

## 支持的命令

### 客户端命令
- `/list` - 查看当前在线用户列表
- `/quit` 或 `/exit` - 退出聊天程序

### 系统消息
- 用户加入/离开聊天室会有系统提示
- 所有消息都会显示时间戳

## 技术特点

- 使用 TCP 协议保证消息可靠传输
- 采用 goroutine 实现并发处理
- 使用 mutex 保证线程安全
- 支持优雅的连接关闭

## 注意事项

- 确保端口 8081 未被占用
- 可以同时运行多个客户端实例
- 服务器支持跨平台运行
